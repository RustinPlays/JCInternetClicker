External inputs / Stream Deck

Turn a USB presenter clicker or local Companion/Stream Deck button into a remote trigger.

USB presenter clicker

Run the receiver on the sending PC, enable Detect USB clicker in its monitor window, then map Right, Left, PageDown or PageUp below. The receiver only reports the selected control keys.

Avoid enabling on the same PC as a locally controlled slideshow: the key could advance it twice. Learn Input can pick up a MIDI or keyboard control without guessing its code.

Stream Deck / Companion

Send a POST from Companion's HTTP Request action to the sender's local receiver at http://127.0.0.1:8877/trigger/BUTTON_ID.

Include header X-Clicker-Key with the local receiver's key. No public port forwarding. Use the Copy endpoint buttons below.

USB clicker key mapping

Local independence

Each remote computer retains its own PowerPoint/Resolume controls. A multi-PC macro sends to selected receivers in order; operating a local show does not automatically advance another location.

Appearance & branding

Safety

The remote receiver only connects outbound and restricts destination networks. Approved scripts are configured on the local receiver, not entered as arbitrary commands from the public website. Never port-forward application control ports.
