JC INTERNET CLICKER / WINDOWS RECEIVER v0.3 BETA

QUICK SETUP
1. Install Python 3.11+ (or use the standalone EXE generated by GitHub Actions).
2. Double-click start-windows.bat. It installs dependencies on first run.
3. On the website: Configuration > Add PC > Pair with code.
4. Enter the HTTPS relay URL and 10-minute pairing code in the receiver setup.
5. Keep the receiver running (minimises to the system tray if pystray installed).
6. Website: Connections & tests > Send test. Watch the receiver log for RECEIVED and ACK SENT.

Optional USB clicker detection captures global key events; it can also affect a local
slide show. Configure mappings from website Inputs tab. For Stream Deck use a local
HTTP POST to http://127.0.0.1:8877/trigger/BUTTON_ID with header X-Clicker-Key.

Config is saved beside app or EXE as config.json; never commit, upload or send it.
MIDI requires a selected MIDI device name (see Studio Local configuration).
Scripts only run if explicitly listed as approved_scripts in config.json.

Test with PowerPoint/Resolume before using during a show.
